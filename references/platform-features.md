# Wordwall 官方功能調查（2026-07）

- 18 種模板（免費版全開，13 種可列印）：Match Up、Random Wheel、Group Sort、Random Cards、Whack-a-Mole、Quiz、Find the Match、Open the Box、Matching Pairs、Missing Word、Gameshow Quiz、Unjumble、Maze Chase、True or False、Anagram 等。
- 建立方式：選模板 → 逐項輸入內容（無批次匯入 API）。
- 一鍵換模板：建好後可一鍵切換到相容模板（差異化/複習），非所有模板互換。
- 指派：活動頁 Share → Set Assignment（是否記名、期限、結束選項）→ 產生指派連結；My Results 追蹤成績。
- 分享：連結、FB/Twitter/Google Classroom/Email/嵌入。
- 列印/下載 PDF。
- 唯一公開讀取 API：oEmbed（wordwall.net/about/oembed），免驗證。
