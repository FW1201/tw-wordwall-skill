# Wordwall 模式與執行

- quiz / match up：先依各模板資料形狀生成內容，核對題幹、配對、來源與答案；相容模板切換、計時與紙本在編輯器實際檢查。
- 分類／字謎／開箱／轉盤等：以既有轉換器 warnings 和 experimental 狀態為準，未經 live 驗證不可當成已支援。迷宮等玩家移動模式需先確認該活動與模板相容。
- 教師操作：以既有登入分頁建立，對照每筆輸入、預覽遊戲與紙本，指派或分享以授權及實際設定為準；讀回網址、模板、可見度。
- 教學設計：寫清楚玩家的操作、目標、挑戰與回饋；如僅能承載問答，誠實說明而非宣稱完整情境遊戲。

官方來源：https://wordwall.net/features （2026-11-26 核對）；本次已用已登入帳號建立 Maze chase 一題活動，正解標記、活動頁與遊戲移動／扣生命已觀察；尚未通關，未驗證 CLI 自動建立。

轉換保護：是非答案須能明確判讀 True/False，無法辨識或正解不唯一則跳過；配對題若有多個正解，停止該題並要求教師選擇，避免靜默丟失；任何題目被跳過時 CLI 回傳 partial、exit code 2。
